# SPEC-07: CI + Release Pipeline

**Project:** `ctxlite`  
**Scope:** GitHub Actions workflows pentru CI (tests pe PR) si release (cross-compile Go + npm publish pe tag)  
**Depinde de:** SPEC-06 (structura npm), SPEC-01–05 (cod Go complet)  
**Agent target:** Cursor AI  
**Status:** `[x] Done`

## Context

Doua workflow-uri independente:

```
ci.yml      → rulat pe orice PR sau push pe main
               - go test ./go/...
               - go build (verifica ca compileaza pe toate platformele)
               - golangci-lint

release.yml → rulat la git tag v*.*.*
               - cross-compile Go pentru 5 platforme in parallel
               - upload binare ca GitHub Release assets
               - copiaza binarele in npm/ctxlite-*/bin/
               - npm publish pentru toate 6 pachetele
```

## `.github/workflows/ci.yml`

```yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  test:
    name: Test (${{ matrix.os }})
    runs-on: ${{ matrix.os }}
    strategy:
      fail-fast: false
      matrix:
        os: [ubuntu-latest, macos-latest, windows-latest]

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Go
        uses: actions/setup-go@v5
        with:
          go-version: "1.22"
          cache: true

      - name: Download dependencies
        run: go mod download
        working-directory: .

      # CGO e necesar pentru go-sqlite3 si go-tree-sitter
      - name: Install CGO dependencies (Linux)
        if: runner.os == 'Linux'
        run: |
          sudo apt-get update -q
          sudo apt-get install -y gcc libc6-dev

      - name: Install CGO dependencies (macOS)
        if: runner.os == 'macOS'
        run: |
          # Xcode Command Line Tools includ gcc — verifica doar
          gcc --version

      - name: Run tests
        run: CGO_ENABLED=1 go test ./go/... -v -race -count=1
        shell: bash

      - name: Build binary (smoke test)
        run: CGO_ENABLED=1 go build -o /dev/null ./go/cmd/ctxlite
        shell: bash
        if: runner.os != 'Windows'

      - name: Build binary (smoke test, Windows)
        run: CGO_ENABLED=1 go build -o ctxlite.exe ./go/cmd/ctxlite
        if: runner.os == 'Windows'

  lint:
    name: Lint
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v5
        with:
          go-version: "1.22"
          cache: true

      - name: Install gcc (CGO)
        run: sudo apt-get install -y gcc

      - name: golangci-lint
        uses: golangci/golangci-lint-action@v6
        with:
          version: v1.59
          args: --timeout=5m ./go/...
          env:
            CGO_ENABLED: "1"

  # Verifica ca package.json-urile npm sunt valid JSON
  npm-validate:
    name: Validate npm packages
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4

      - name: Validate package.json files
        run: |
          for pkg in npm/ctxlite npm/ctxlite-darwin-arm64 npm/ctxlite-darwin-x64 \
                     npm/ctxlite-linux-x64 npm/ctxlite-linux-arm64 npm/ctxlite-win32-x64; do
            echo "Validating $pkg/package.json..."
            node -e "require('./$pkg/package.json')"
          done

      - name: Check ctxlite.js syntax
        run: node --check npm/ctxlite/bin/ctxlite.js
```

## `.github/workflows/release.yml`

```yaml
name: Release

on:
  push:
    tags:
      - "v*.*.*"   # Trigger pe orice tag de forma v0.1.0, v1.2.3 etc.

permissions:
  contents: write    # pentru GitHub Release + upload assets
  id-token: write    # pentru npm provenance (viitor)

jobs:
  # ── Job 1: Build Go binar pentru fiecare platforma ──────────────
  build:
    name: Build ${{ matrix.goos }}-${{ matrix.goarch }}
    runs-on: ${{ matrix.runner }}
    strategy:
      fail-fast: false
      matrix:
        include:
          - goos: darwin
            goarch: arm64
            runner: macos-14          # Apple Silicon runner
            npm_pkg: ctxlite-darwin-arm64
            bin_name: ctxlite
            asset_name: ctxlite-darwin-arm64

          - goos: darwin
            goarch: amd64
            runner: macos-13          # Intel runner
            npm_pkg: ctxlite-darwin-x64
            bin_name: ctxlite
            asset_name: ctxlite-darwin-x64

          - goos: linux
            goarch: amd64
            runner: ubuntu-latest
            npm_pkg: ctxlite-linux-x64
            bin_name: ctxlite
            asset_name: ctxlite-linux-x64

          - goos: linux
            goarch: arm64
            runner: ubuntu-latest
            npm_pkg: ctxlite-linux-arm64
            bin_name: ctxlite
            asset_name: ctxlite-linux-arm64

          - goos: windows
            goarch: amd64
            runner: windows-latest
            npm_pkg: ctxlite-win32-x64
            bin_name: ctxlite.exe
            asset_name: ctxlite-win32-x64.exe

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Go
        uses: actions/setup-go@v5
        with:
          go-version: "1.22"
          cache: true

      # Cross-compiler pentru linux-arm64 (ruleaza pe ubuntu-latest x64)
      - name: Install ARM64 cross-compiler (Linux)
        if: matrix.goos == 'linux' && matrix.goarch == 'arm64'
        run: |
          sudo apt-get update -q
          sudo apt-get install -y gcc-aarch64-linux-gnu

      - name: Install CGO dependencies (Linux x64)
        if: matrix.goos == 'linux' && matrix.goarch == 'amd64'
        run: sudo apt-get install -y gcc

      - name: Extract version from tag
        id: version
        shell: bash
        run: echo "VERSION=${GITHUB_REF_NAME#v}" >> $GITHUB_OUTPUT

      # Build cu ldflags pentru a injecta versiunea in binar
      - name: Build binary (linux-arm64, cross-compile)
        if: matrix.goos == 'linux' && matrix.goarch == 'arm64'
        run: |
          CGO_ENABLED=1 \
          GOOS=linux \
          GOARCH=arm64 \
          CC=aarch64-linux-gnu-gcc \
          go build \
            -ldflags="-s -w -X main.version=${{ steps.version.outputs.VERSION }}" \
            -o ${{ matrix.bin_name }} \
            ./go/cmd/ctxlite

      - name: Build binary (native)
        if: matrix.goos != 'linux' || matrix.goarch != 'arm64'
        shell: bash
        run: |
          CGO_ENABLED=1 \
          GOOS=${{ matrix.goos }} \
          GOARCH=${{ matrix.goarch }} \
          go build \
            -ldflags="-s -w -X main.version=${{ steps.version.outputs.VERSION }}" \
            -o ${{ matrix.bin_name }} \
            ./go/cmd/ctxlite

      # Verifica ca binarul porneste si afiseaza versiunea corecta
      - name: Smoke test binary
        if: matrix.goos != 'windows'
        run: |
          chmod +x ./${{ matrix.bin_name }}
          ./${{ matrix.bin_name }} --version

      - name: Smoke test binary (Windows)
        if: matrix.goos == 'windows'
        run: .\${{ matrix.bin_name }} --version

      # Upload binar ca artifact pentru job-ul de publish
      - name: Upload binary artifact
        uses: actions/upload-artifact@v4
        with:
          name: ${{ matrix.asset_name }}
          path: ${{ matrix.bin_name }}
          if-no-files-found: error
          retention-days: 1

  # ── Job 2: Creeaza GitHub Release si publica pe npm ─────────────
  publish:
    name: Publish
    needs: build              # asteapta toate build job-urile
    runs-on: ubuntu-latest

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: "20"
          registry-url: "https://registry.npmjs.org"

      - name: Extract version from tag
        id: version
        run: echo "VERSION=${GITHUB_REF_NAME#v}" >> $GITHUB_OUTPUT

      # Descarca toate binarele din job-urile de build
      - name: Download all binaries
        uses: actions/download-artifact@v4
        with:
          path: artifacts/

      # Listeaza ce s-a descarcat (debug)
      - name: List artifacts
        run: find artifacts/ -type f

      # Copiaza binarele in structura npm
      - name: Copy binaries to npm packages
        run: |
          set -e

          install_bin() {
            local src="$1"
            local dst_dir="$2"
            local dst_name="$3"

            mkdir -p "$dst_dir"
            cp "$src" "$dst_dir/$dst_name"
            chmod +x "$dst_dir/$dst_name" 2>/dev/null || true
            echo "Installed: $dst_dir/$dst_name"
          }

          install_bin \
            "artifacts/ctxlite-darwin-arm64/ctxlite" \
            "npm/ctxlite-darwin-arm64/bin" \
            "ctxlite"

          install_bin \
            "artifacts/ctxlite-darwin-x64/ctxlite" \
            "npm/ctxlite-darwin-x64/bin" \
            "ctxlite"

          install_bin \
            "artifacts/ctxlite-linux-x64/ctxlite" \
            "npm/ctxlite-linux-x64/bin" \
            "ctxlite"

          install_bin \
            "artifacts/ctxlite-linux-arm64/ctxlite" \
            "npm/ctxlite-linux-arm64/bin" \
            "ctxlite"

          install_bin \
            "artifacts/ctxlite-win32-x64.exe/ctxlite.exe" \
            "npm/ctxlite-win32-x64/bin" \
            "ctxlite.exe"

      # Sincronizeaza versiunea in toate package.json-urile
      - name: Update npm package versions
        run: make npm-version VERSION=${{ steps.version.outputs.VERSION }}

      # Copiaza README in pachetul principal
      - name: Copy README to npm package
        run: cp README.md npm/ctxlite/README.md

      # Publica pachetele platform-specific INTAI
      # (pachetul principal depinde de ele via optionalDependencies)
      - name: Publish platform packages
        env:
          NODE_AUTH_TOKEN: ${{ secrets.NPM_TOKEN }}
        run: |
          set -e
          for pkg in \
            npm/ctxlite-darwin-arm64 \
            npm/ctxlite-darwin-x64 \
            npm/ctxlite-linux-x64 \
            npm/ctxlite-linux-arm64 \
            npm/ctxlite-win32-x64; do
            echo "Publishing $pkg..."
            cd "$pkg"
            npm publish --access public
            cd "$GITHUB_WORKSPACE"
            # Mici pauze intre publish-uri pentru a evita rate limiting
            sleep 2
          done

      # Publica pachetul principal (wrapper)
      - name: Publish main package
        env:
          NODE_AUTH_TOKEN: ${{ secrets.NPM_TOKEN }}
        run: |
          cd npm/ctxlite
          npm publish --access public

      # Creeaza GitHub Release cu binarele ca assets
      - name: Create GitHub Release
        uses: softprops/action-gh-release@v2
        with:
          name: "ctxlite ${{ github.ref_name }}"
          draft: false
          prerelease: ${{ contains(github.ref_name, '-') }}  # v0.1.0-beta = prerelease
          generate_release_notes: true
          files: |
            artifacts/ctxlite-darwin-arm64/ctxlite
            artifacts/ctxlite-darwin-x64/ctxlite
            artifacts/ctxlite-linux-x64/ctxlite
            artifacts/ctxlite-linux-arm64/ctxlite
            artifacts/ctxlite-win32-x64.exe/ctxlite.exe
          body: |
            ## Install

            ```bash
            npm install -g ctxlite
            ```

            Or download the binary directly for your platform below.

            ## What's changed

            <!-- generated_release_notes -->

            ## Checksums

            Run `sha256sum ctxlite-*` to verify downloaded binaries.
```

## Secret de configurat in GitHub

Un singur secret necesar:

```
NPM_TOKEN
```

**Cum se obtine:**
1. `npm login` pe npmjs.com
2. `npm token create --type=automation`
3. In GitHub repo → Settings → Secrets → Actions → `New repository secret`
4. Name: `NPM_TOKEN`, Value: tokenul generat

Documenteaza asta in `docs/contributing.md`:

## Publishing a new release (maintainers only)

1. Update version in `go/cmd/ctxlite/main.go`: `const version = "X.Y.Z"`
2. Update `CHANGELOG.md`
3. Commit: `git commit -m "chore: release vX.Y.Z"`
4. Tag: `git tag vX.Y.Z`
5. Push: `git push origin main --tags`

- Publish 6 npm packages

## Versiunea injectata in binar

In `main.go`, versiunea e hardcodata:

```go
const version = "0.1.0"
```

CI-ul o suprascrie la build cu `-ldflags="-X main.version=X.Y.Z"`.  
Pentru asta, `version` trebuie sa fie o variabila, nu o constanta:

```go
// In go/cmd/ctxlite/main.go, schimba:
const version = "0.1.0"
// La:
var version = "0.1.0" // overridden by -ldflags at build time
```

## Makefile update — build cu version inject

```makefile
VERSION := $(shell git describe --tags --always --dirty 2>/dev/null || echo "dev")
LDFLAGS := -ldflags="-s -w -X main.version=$(VERSION)"

build:
	CGO_ENABLED=1 go build $(LDFLAGS) -o bin/ctxlite ./go/cmd/ctxlite

build-all:
	CGO_ENABLED=1 GOOS=darwin  GOARCH=arm64 go build $(LDFLAGS) -o bin/ctxlite-darwin-arm64  ./go/cmd/ctxlite
	CGO_ENABLED=1 GOOS=darwin  GOARCH=amd64 go build $(LDFLAGS) -o bin/ctxlite-darwin-x64    ./go/cmd/ctxlite
	CGO_ENABLED=1 GOOS=linux   GOARCH=amd64 go build $(LDFLAGS) -o bin/ctxlite-linux-x64     ./go/cmd/ctxlite
	CGO_ENABLED=1 GOOS=linux   GOARCH=arm64 \
	  CC=aarch64-linux-gnu-gcc  go build $(LDFLAGS) -o bin/ctxlite-linux-arm64   ./go/cmd/ctxlite
	CGO_ENABLED=1 GOOS=windows GOARCH=amd64 go build $(LDFLAGS) -o bin/ctxlite-win32-x64.exe ./go/cmd/ctxlite
```
