## Context

`ctxlite` este un token optimizer open source pentru Cursor, OpenCode si Claude Code.  
Functioneaza ca:
1. **HTTP proxy local** pe `127.0.0.1:8080` — intercepteaza calls catre Anthropic/OpenAI API, face caching si context trimming
2. **MCP server** pe stdio — expune tools (`trim_context`, `get_stats`) catre coding tools

Aceasta spec acopera **doar scaffolding-ul initial** — structura de fisiere, config, documentatie si un `main.go` functional care porneste ambele servere si se opreste graceful.

# Go Style Rules

## General
- Go version: 1.22+
- Module path: github.com/ctxlite/ctxlite
- Toate erorile se returneaza explicit, nu se ignora cu `_`
- Nu folosi `panic()` in afara de `main.go` la startup validation
- Prefer `errors.New()` si `fmt.Errorf("context: %w", err)` pentru error wrapping

## Naming
- Package names: lowercase, un singur cuvant (ex: `proxy`, `cache`, `trimmer`, `mcp`, `stats`)
- Interfaces: suffix `-er` cand are sens (ex: `Cacher`, `Trimmer`)
- Exported functions: PascalCase
- Internal helpers: camelCase
- Constants: ALL_CAPS doar pentru erori sentinela, altfel PascalCase

## Structure
- Fiecare package are un fisier `doc.go` cu comentariul pachetului
- Constructori au forma `New<Type>(config Config) (*Type, error)`
- Cleanup prin `io.Closer` interface, nu prin metode custom

## HTTP
- Bind INTOTDEAUNA pe `127.0.0.1`, niciodata pe `0.0.0.0`
- Timeout-uri obligatorii pe orice `http.Server`: ReadTimeout, WriteTimeout, IdleTimeout
- Nu loga niciodata Authorization headers sau API keys

## Logging
- Foloseste `log/slog` (stdlib, Go 1.21+)
- Level default: `INFO`
- Format: text pe stderr (nu JSON in v1)
- Nu loga request body sau response body — pot contine date sensibile

## Testing
- Fiecare package are fisier `*_test.go`
- Foloseste `testing` stdlib, nu framework-uri externe
- Table-driven tests pentru logica de cache si trimming
```

# Security Rules

## Network
- HTTP server se bindeaza EXCLUSIV pe 127.0.0.1, niciodata pe 0.0.0.0
- Nu face outbound requests catre alte domenii in afara de api.anthropic.com si api.openai.com
- Timeout obligatoriu pe orice outbound HTTP call: max 120s

## Secrets
- Nu stoca niciodata Authorization header in SQLite sau in logs
- Nu loga URL-uri care contin query params cu tokens
- API keys raman in memorie doar pe durata unui request

## Cache
- Cheile de cache se calculeaza din request body (fara headers)
- Response-urile se stocheaza fara headerele de autentificare

## Input validation
- Valideaza Content-Type pe orice request primit
- Limiteaza request body size la 10MB (configurabil)
- Returneaza 400 pentru request-uri malformate, nu 500
```

### `go/cmd/ctxlite/main.go`

Entry point. Porneste proxy HTTP si MCP server, gestioneaza graceful shutdown.

**Comportament asteptat:**
- La start: printeaza pe stderr `ctxlite v0.1.0 running — proxy :8080 | mcp stdio`
- Asculta SIGTERM si SIGINT pentru graceful shutdown
- La shutdown: printeaza session summary pe stderr (hardcodat cu zeros in v1)
- Exit code 0 pe shutdown normal, 1 pe eroare de start

**Interfata CLI (v1 minimal):**
```
ctxlite [flags]

Flags:
  --port int      Port pentru HTTP proxy (default: 8080)
  --db string     Path catre SQLite db (default: ~/.ctxlite/cache.db)
  --verbose       Verbose logging
  --version       Printeaza versiunea si iese
```

**Implementare:**

```go
package main

import (
    "context"
    "flag"
    "fmt"
    "log/slog"
    "os"
    "os/signal"
    "syscall"

    "github.com/ctxlite/ctxlite/go/internal/proxy"
    "github.com/ctxlite/ctxlite/go/internal/stats"
)

const version = "0.1.0"

func main() {
    // flags
    port    := flag.Int("port", 8080, "HTTP proxy port")
    dbPath  := flag.String("db", defaultDBPath(), "SQLite cache database path")
    verbose := flag.Bool("verbose", false, "Verbose logging")
    ver     := flag.Bool("version", false, "Print version")
    flag.Parse()

    if *ver {
        fmt.Printf("ctxlite v%s\n", version)
        os.Exit(0)
    }

    // logging
    level := slog.LevelInfo
    if *verbose {
        level = slog.LevelDebug
    }
    slog.SetDefault(slog.New(slog.NewTextHandler(os.Stderr, &slog.HandlerOptions{Level: level})))

    // stats store
    store, err := stats.New(*dbPath)
    if err != nil {
        slog.Error("failed to open stats db", "err", err)
        os.Exit(1)
    }
    defer store.Close()

    // proxy server
    srv, err := proxy.New(proxy.Config{
        Port:  *port,
        Store: store,
    })
    if err != nil {
        slog.Error("failed to create proxy", "err", err)
        os.Exit(1)
    }

    // start
    slog.Info(fmt.Sprintf("ctxlite v%s running", version),
        "proxy", fmt.Sprintf("127.0.0.1:%d", *port),
        "mcp", "stdio",
        "db", *dbPath,
    )

    ctx, stop := signal.NotifyContext(context.Background(), syscall.SIGTERM, syscall.SIGINT)
    defer stop()

    go func() {
        if err := srv.Start(); err != nil {
            slog.Error("proxy error", "err", err)
            stop()
        }
    }()

    // MCP server pe stdio — SPEC-05
    // go mcp.Serve(ctx, store)

    <-ctx.Done()

    slog.Info("shutting down...")
    srv.Stop()
    printSessionSummary(store)
}

func defaultDBPath() string {
    home, _ := os.UserHomeDir()
    return home + "/.ctxlite/cache.db"
}

func printSessionSummary(store *stats.Store) {
    summary := store.SessionSummary()
    fmt.Fprintf(os.Stderr, `
ctxlite session summary
───────────────────────────────────────
Requests      %d total   %d hits (%.1f%%)
Tokens saved  %d
Cost saved    ~$%.2f
───────────────────────────────────────
`,
        summary.TotalRequests,
        summary.CacheHits,
        summary.HitRate(),
        summary.TokensSaved,
        summary.CostSaved,
    )
}
```

ctxlite runs as a local HTTP proxy on `127.0.0.1:8080`.  
Your coding tool sends requests to ctxlite instead of directly to the LLM API.

```
Cursor / OpenCode / Claude Code
         ↓
   ctxlite :8080

    └── context trimmer         → forward trimmed request
         ↓
   Anthropic / OpenAI API
```

# Architecture

## Overview

ctxlite has two components running in a single process:

### 1. HTTP Proxy (`internal/proxy`)
Intercepts all LLM API calls. Compatible with any OpenAI-compatible endpoint
and the Anthropic API.

**Request lifecycle:**
```
Request in
  → extract body (strip auth headers)
  → L1 cache lookup (SHA256 exact match)
    → HIT: return cached response
  → L2 cache lookup (cosine similarity via sqlite-vec)
    → HIT (>= 0.92): return cached response
  → context trimmer (BM25 relevance scoring)
  → forward trimmed request to upstream API
  → cache response
  → return to client
```

### 2. MCP Server (`internal/mcp`)
Exposes tools to Cursor, OpenCode and Claude Code via stdio transport.

**Tools:**
- `trim_context` — explicitly trim a list of files to the most relevant ones
- `get_stats` — return current session statistics

## Data flow

```
[Client Tool] → HTTP → [proxy.go] → [cache/exact.go] → HIT → [Client Tool]
                                  ↓ MISS
                             [cache/semantic.go] → HIT → [Client Tool]
                                  ↓ MISS
                             [trimmer/bm25.go]
                                  ↓
                             [Upstream API]
                                  ↓
                             [stats/stats.go] (log request)
                                  ↓
                             [Client Tool]
```

## Security model

- Proxy binds on `127.0.0.1` only — not accessible from network
- API keys are forwarded per-request and never stored
- Cache keys are derived from request body only (no auth headers)
- SQLite database is stored in `~/.ctxlite/` with user-only permissions
```
