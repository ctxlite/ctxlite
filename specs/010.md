## `.cursor/rules/ts-style.mdc`

```markdown
---
description: TypeScript style rules for ctxlite
globs: ["**/*.ts"]
alwaysApply: true
---

# TypeScript Style Rules

## General
- TypeScript strict mode: true
- Node.js >= 18 (ESM modules)
- Toate erorile se returneaza explicit — no throw pentru flow normal
- Prefer `Result<T, E>` pattern peste throw/catch pentru erori de business logic

## Naming
- Interfaces: PascalCase, fara prefix I
- Types: PascalCase
- Functions: camelCase
- Constants: SCREAMING_SNAKE_CASE pentru env vars, camelCase pentru restul
- Fisiere: kebab-case (ex: bm25.ts, token-counter.ts)

## Imports
- ESM only — "type": "module" in package.json
- Imports cu extensie .js (chiar daca fisierul e .ts — TypeScript ESM requirement)
- No default exports — named exports only

## Async
- Async/await peste .then()/.catch()
- Nu ignora Promise-uri neawaited

## Logging
- Nu folosi console.log in library code (core, opencode, mcp)
- console.error permis in CLI si entry points
- Nu loga niciodata API keys, tokens, sau request/response bodies

## Testing
- Vitest pentru toate testele
- Table-driven tests cu it.each()
- Nu mock-ui filesystem — foloseste tmp directories reale
```

## `.cursor/rules/repo-structure.mdc`

```markdown
---
description: Monorepo structure conventions
globs: ["**/*"]
alwaysApply: true
---

# Monorepo Structure

## Packages
- `@ctxlite/core` — logica shared: BM25, stats SQLite, token counting, parser
- `@ctxlite/opencode` — OpenCode plugin
- `@ctxlite/mcp` — MCP stdio server pentru Cursor editor + Cursor agent CLI
- `ctxlite` (CLI) — `ctxlite stats` command

## Reguli
- Logica de business DOAR in @ctxlite/core
- Pachetele opencode si mcp importa din core, nu isi duplica logica
- CLI importa din core direct
- Nu exista dependinte circulare intre pachete

## Versioning
- Toate pachetele au aceeasi versiune (synchronized versioning)
- Versiunea e definita o singura data in root package.json ca `config.version`
- Script-ul `sync-version` o propaga in toate pachetele
```

```markdown
---
description: Security rules
globs: ["**/*.ts"]
alwaysApply: true
---

# Security Rules

## Secrets
- Nu stoca niciodata API keys, session tokens, sau Authorization headers in SQLite
- Nu loga request sau response bodies — pot contine date sensibile
- SQLite db doar in ~/.ctxlite/ cu permisiuni user-only

## Input
- Valideaza toate inputurile externe cu zod
- Limiteaza size-ul textelor procesate (max 1MB per fisier pentru BM25)

## Dependencies
- Minimizeaza dependintele externe
- Audiaza cu `npm audit` la fiecare release
- Nu adauga dependinte cu CVE-uri known
```

## `scripts/sync-version.js`

```js
#!/usr/bin/env node
// Sincronizeaza versiunea din root config.version in toate package.json-urile

import { readFileSync, writeFileSync } from "fs"
import { join } from "path"

const root = JSON.parse(readFileSync("package.json", "utf8"))
const version = root.config.version

const packages = [
  "packages/core/package.json",
  "packages/opencode/package.json",
  "packages/mcp/package.json",
  "packages/cli/package.json",
]

for (const pkgPath of packages) {
  const pkg = JSON.parse(readFileSync(pkgPath, "utf8"))
  pkg.version = version

  // Actualizeaza si dependintele interne
  for (const dep of ["dependencies", "devDependencies", "peerDependencies"]) {
    if (!pkg[dep]) continue
    for (const name of Object.keys(pkg[dep])) {
      if (name.startsWith("@ctxlite/")) {
        pkg[dep][name] = version
      }
    }
  }

  writeFileSync(pkgPath, JSON.stringify(pkg, null, 2) + "\n")
  console.log(`Updated ${pkgPath} → v${version}`)
}
```

## `README.md`

```markdown
# ctxlite

> Token optimizer pentru OpenCode si Cursor — context trimming + stats reporting.

[![CI](https://github.com/ctxlite/ctxlite/actions/workflows/ci.yml/badge.svg)](https://github.com/ctxlite/ctxlite/actions)
[![npm](https://img.shields.io/npm/v/@ctxlite/opencode)](https://www.npmjs.com/package/@ctxlite/opencode)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## Cum functioneaza

ctxlite analizeaza fisierele din contextul tau si le trimiteaza la model
doar pe cele relevante pentru task-ul curent, folosind BM25 scoring.
Rezultat: mai putini tokens consumati, raspunsuri mai rapide, costuri mai mici.

## Install

### OpenCode
```bash
opencode plugin @ctxlite/opencode -g
```

### Cursor (editor + agent CLI)
```json
// ~/.cursor/mcp.json
{
  "mcpServers": {
    "ctxlite": {
      "command": "npx",
      "args": ["-y", "@ctxlite/mcp"]
    }
  }
}
```

## Stats

```bash
npx ctxlite stats
npx ctxlite stats --last 7d
npx ctxlite stats --export json
```
