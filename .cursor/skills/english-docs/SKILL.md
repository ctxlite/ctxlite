# English Documentation

All documentation in the ctxlite repository must be written in English.

## Applies to

- `README.md` and all files under `docs/`
- GoDoc comments on exported types, functions, and constants
- `CHANGELOG.md`, issue templates, and contribution guides
- CLI help text and user-facing log messages intended for end users
- Cursor rules and project skills (`.cursor/rules/`, `.cursor/skills/`)

## Does not apply to

- Internal spec files under `specs/` (excluded from the repository)
- Third-party quotes or API identifiers that must remain verbatim

## Guidelines

- Use clear, concise technical English
- Prefer active voice and complete sentences
- Keep terminology consistent: "HTTP proxy", "cache hit", "context trimming"
- Do not mix languages in the same document
